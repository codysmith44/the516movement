# The 516 Movement: WordPress block theme (trial rebuild)
A modern block theme rebuild of the516movement.com (M516, Inc.).

- Try it: https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/codysmith44/the516movement/main/blueprint.json
- `theme/the516movement/` is the theme source; `the516movement-theme.zip` is the installable zip
- `build.py` regenerates the theme and blueprints (`python3 build.py`, then re-zip)
- `site-notes.md` has notes on the original site; `screenshots/` has the local renders
- The booking, contact and donation forms are placeholders (they need a form plugin and GiveWP).
